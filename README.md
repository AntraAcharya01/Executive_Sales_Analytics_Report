📌 Project Overview

This project is an interactive Power BI Sales Performance Dashboard designed to analyze and compare Actual Sales vs Target Sales across different teams and quarters.

The dashboard provides actionable insights into sales performance, target achievement, quarterly trends, and KPI tracking to support data-driven business decisions.

🚀 Key Features
📊 Actual vs Target Sales comparison
📈 Quarterly sales performance analysis
👥 Team-wise sales categorization
📉 Variance analysis between actual and target values
📋 Trend analysis using tabular visuals
🎯 KPI cards for quick business insights
🔄 Interactive filtering and drill-down capabilities
📊 Dashboard Insights

The dashboard helps stakeholders:

Monitor overall sales performance
Identify underperforming and high-performing teams
Analyze quarterly growth trends
Track sales variance against targets
Support strategic planning and decision-making
📌 KPIs Included
Total Actual Sales
Total Target Sales
Sales Variance
Variance Percentage
Quarterly Performance Metrics
📈 Visualizations Used
Column Charts for quarterly comparison
KPI Cards for summary metrics
Tables for trend and detailed analysis
Slicers for interactive filtering

Excel / CSV Data Sources

This dashboard can be used by:
